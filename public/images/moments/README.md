# Beyond the Code — real event photos

Drop your real event photographs here (WebP/JPEG recommended), then list them in
`src/data/beyondTheCodeData.ts` as:

```ts
{ image: "/images/moments/devfest-2025-01.webp" }
```

Only add photos you are cleared to publish (organizer rights + consent for
identifiable faces). The gallery intentionally shows no captions — the photos
tell the story.
